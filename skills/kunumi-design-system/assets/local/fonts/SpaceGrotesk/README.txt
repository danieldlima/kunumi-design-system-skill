Space Grotesk
=============

Bundled as the offline-available display face for Kunumi titles.

The Brandbook Kunumi Final (2025) states that titles are set in "PP Neue Machina inktrap ou
Space Grotesk". PP Neue Machina is a commercial face from Pangram Pangram and is NOT bundled
here. Space Grotesk is licensed under the SIL Open Font License 1.1 (see OFL.txt) and may be
redistributed, so it ships with this skill as the dependable fallback.

Resolution order for the display face:
  1. PP Neue Machina Inktrap  - only if licensed and present on the system
  2. Space Grotesk            - this file, the offline default
  3. Figtree SemiBold, uppercase - last resort; state the substitution on delivery

File: SpaceGrotesk[wght].ttf - variable font, weight axis 300-700.
Source: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
Upstream: https://github.com/floriankarsten/space-grotesk
Copyright 2020 The Space Grotesk Project Authors.

Titles are ALWAYS set uppercase and tracked +3%. See references/typography.md.
